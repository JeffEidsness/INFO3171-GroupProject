Page Layouts

How the DailyTube dashboard is arranged: the order of content, and the structure of each card.

Dashboard layout

The dashboard follows an inverted pyramid: the most important information sits at the top left, followed by trends and then detail. The three single-value KPI cards come first so management sees the headline numbers within five seconds. The six charts follow in a grid below.

Usage

  • Do: place KPI cards first. They answer the headline questions immediately.
  • Do: put related charts next to each other, e.g. the two country charts.
  • Do: keep the dashboard to nine visualizations or fewer (5–9 is the guideline).
  • Don't: hide charts in tabs. Everything important should be visible without extra clicks.

Accessibility

The visual order matches the order in the HTML, so screen reader and keyboard users move through the dashboard in the same sequence that sighted users read it.

Code

<main class="dashboard">
  <section class="kpi-row">
    <!-- 3 KPI cards -->
  </section>
  <section class="dash-grid">
    <!-- 6 chart cards -->
  </section>
</main>

Card anatomy

Every chart lives in a card with the same structure. The client asked for individual boxes with rounded borders, so every card uses a 16px radius. This pattern covers the card's structure and spacing; its interactive states are documented on the Components page.

  1. Title: Alatsi, --fs-chart-title. Describes what the chart shows.
  2. Controls: optional dropdowns, buttons or toggles, aligned right.
  3. Chart area: the D3 SVG, scaling to the card's width.
  4. Footer: optional source or note, --fs-xs.

Specs

  • Corner radius: --radius-lg (16px)
  • Padding: --space-5 (24px)
  • Background: --color-surface (white) on --color-bg (Cloud)
  • Border: 1px --color-border; shadow: --shadow-card
  • Gap between title row and chart: --space-4 (16px)

Accessibility

Each card is a section with the chart title as its heading, and the chart SVG has an aria-label summarizing the data.

Code

<section class="chart-card">
  <div class="chart-card-header">
    <h2 class="chart-title">Chart title</h2>
    <div class="chart-controls">...</div>
  </div>
  <div class="chart-area"><!-- D3 SVG --></div>
</section>

.chart-card {
  padding: var(--space-5);
  background: var(--color-surface);
  border: 1px solid var(--color-border);
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-card);
}
