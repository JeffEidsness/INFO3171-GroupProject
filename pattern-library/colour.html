Colour

DailyTube's palette is built around the brand gold #FFBD59 and kept monochromatic — warm neutrals from near-white to near-black, with focused feedback tones. All text-on-background pairings meet WCAG 2.1 AA contrast (4.5:1 for body text).

Colour Usage Guide

  • Sunburst (#FFBD59) — active menu item underline, KPI highlights, chart Series 1. Never use as a text colour on white.
  • Amber Deep (#C98A00) — primary buttons, links. Passes AA on white so safe for inline text.
  • Honey Tint (#FFE0A3) — chart highlight/brush fill, selected row bg, tooltip bg tint.
  • Cloud (#F7F7F8) — overall page background. Cards sit on white (#FFFFFF) above it.
  • Pitch (#1A1A1B) — all body text, chart axis labels, legend text.
  • Graphite (#3A3A3C) — secondary text, metadata, chart tick labels.
  • Mist (#E2E2E4) — card borders, table rules, dividers.
  • Feedback colours — appear only in status badges and notification banners, never in charts or decorative use.
  • Accent series — apply in order (Sunburst → Tangerine → Rust → Butter → Amber Deep → Graphite) across chart series. Rotate if more than 6 series.
