Typography

DailyTube uses two typefaces: a bold display face that echoes the logo, and a rounded, friendly body face that reflects the brand's creativity and positivity.

Typefaces

Alatsi is the display typeface for headings, menus and KPI numbers. Quicksand is used for body text, buttons, forms and all chart data. Each has a full sans-serif fallback stack, so text stays readable if a font fails to load.

Usage

  • Do: use Alatsi for headings, the navigation menu and KPI numbers.
  • Do: use Quicksand for everything else, including all chart text.
  • Don't: add a third typeface. Two is the maximum.
  • Don't: make Alatsi bold. It has one weight, and browsers fake bold badly.
  • Don't: use decorative fonts in charts.

Accessibility

Both fonts end in a system font stack (system-ui, Segoe UI, Roboto, Arial, sans-serif), so every device shows a clear sans-serif even if the web fonts fail to load.

Code

/* variables.css */
--font-fallback: system-ui, -apple-system, "Segoe UI", Roboto,
                 "Helvetica Neue", Arial, sans-serif;
--font-display: 'Alatsi', var(--font-fallback);
--font-body:    'Quicksand', var(--font-fallback);
--font-data:    'Quicksand', var(--font-fallback);

Type scale

Sizes follow a 1.25 ratio from a 16px base, so every level is clearly different from the next. Sizes use rem so they respect the user's browser font settings. Headings shrink on screens narrower than 600px.

H1 · --fs-h1 · 3.052rem / 49px Dashboard
H2 · --fs-h2 · 2.441rem / 39px Channel trends
H3 · --fs-h3 · 1.953rem / 31px Top categories
H4 · --fs-h4 · 1.563rem / 25px Card title
H5 · --fs-h5 · 1.25rem / 20px Minor heading
Lead · --fs-lead · 1.125rem / 18px Introductory paragraph text
Body · --fs-body · 1rem / 16px Body text for descriptions and content
Small · --fs-small · 0.875rem / 14px Captions and metadata
XS · --fs-xs · 0.75rem / 12px Fine print, the minimum size

Usage

  • Do: use one H1 per page, for the page title.
  • Do: pick a heading by its place in the page structure, not its size.
  • Don't: type sizes directly. Always use a --fs token.
  • Don't: go below 12px (--fs-xs) for any text.

Accessibility

Rem units scale with the user's browser font size, so people who enlarge text get a proportionally larger page. Headings in order (H1, then H2, then H3) let screen readers navigate the page.

Code

/* variables.css */
--fs-h1: 3.052rem;
--fs-h2: 2.441rem;
--fs-h3: 1.953rem;
--fs-h4: 1.563rem;
--fs-h5: 1.25rem;
--fs-body: 1rem;
--fs-small: 0.875rem;
--fs-xs: 0.75rem;

/* typography.css */
h1 { font-size: var(--fs-h1); }
h2 { font-size: var(--fs-h2); }

Weights & line height

Quicksand comes in four weights. Body text uses Medium (500) because Regular (400) is thin and harder to read on screen. Paragraphs use a 1.6 line height; headings and chart labels use a tighter 1.2.

Medium 500: DailyTube gives everyone a voice

Semibold 600: DailyTube gives everyone a voice

Bold 700: DailyTube gives everyone a voice

Usage

  • Medium (500): body text and descriptions.
  • Semibold (600): labels, buttons, axis titles, KPI labels.
  • Bold (700): short emphasis only, never whole paragraphs.
  • Regular (400): Alatsi headings (its only weight).

Accessibility

Avoid Regular 400 for small text. Thin strokes at small sizes lose contrast, especially on low-quality screens.

Code

--fw-regular:  400;
--fw-medium:   500;
--fw-semibold: 600;
--fw-bold:     700;

--lh-tight: 1.2;  /* headings, chart labels */
--lh-body:  1.6;  /* paragraphs */

Chart typography

Every chart uses the same text hierarchy: a title, axis titles, tick labels and, for single-value charts, a large KPI number. The chart title is larger than any chart text but smaller than section headings, which keeps titles and charts in balance.

Sizes

  • Chart title: Alatsi, --fs-chart-title (18px)
  • Axis title: Quicksand Semibold, --fs-axis-title (14px)
  • Tick labels: Quicksand Medium, --fs-tick (12px)
  • Legend and tooltip: Quicksand, 14px
  • KPI value: Alatsi, --fs-kpi-value (40px); KPI label: Quicksand Semibold uppercase, 14px

Usage

  • Do: give every chart a title and both axis titles.
  • Do: style chart text with classes, never with D3 size attributes.
  • Don't: rotate tick labels. Use a horizontal bar chart for long category names instead.

Accessibility

Tick labels never go below 12px. Chart text is dark grey on white for strong contrast, and every chart SVG has an aria-label describing what it shows.

Code

<!-- HTML -->
<p class="chart-title">YouTube channels by category: India</p>

/* D3: apply the classes instead of setting sizes */
svg.append("text")
  .attr("class", "axis-title")
  .text("Number of channels");

/* typography.css */
.tick-label,
.tick text {
  font-family: var(--font-data);
  font-size: var(--fs-tick);
  fill: var(--color-text-secondary);
}
